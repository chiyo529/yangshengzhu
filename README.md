# 养生主

一个轻量的呼吸节拍器. 设置吸气时间、呼气时间和总时长, 用高低两种无语音钟声跟随呼吸.

## 使用

在线页面发布后可直接在浏览器中打开. 也可下载本仓库, 双击 `index.html` 本地离线使用, 无需安装依赖.

- 吸气和呼气每阶段支持 1 至 60 秒, 以 0.5 秒为单位.
- 支持暂停、继续、重置及音量调整.
- 两枚试听按钮可分别试听吸气的高音钟声和呼气的低音钟声.
- 钟声由浏览器在本机合成, 无语音, 不依赖在线音频文件.
- 浏览器允许时会在本机记住最近设置, 不上传数据或保存练习历史.
- 使用时请保持设备唤醒; 锁屏、休眠或系统限制可能中断声音.

以舒适为准, 不需要吸满、呼尽或屏息. 如有头晕、手麻或憋气等不适, 停止练习并恢复自然呼吸.

## 文件

- `index.html`: 页面入口.
- `styles.css`: 样式.
- `core.js`: 参数校验和呼吸时间轴.
- `app.js`: 交互、钟声和动画.

## GitHub Pages

这是无需构建的静态网页. 在仓库 Settings / Pages 中, 选择 Deploy from a branch, 使用 `main` 分支的 `/ (root)` 目录即可发布. 私有个人仓库需要支持私有仓库 Pages 的 GitHub 套餐.

仓库保持私有时, 发布后的网页及其 HTML、CSS、JavaScript 仍可被网页访问者获取.
