# 养生主

一个轻量的呼吸节拍器. 设置吸气时间、呼气时间和总时长, 用单次、双次无语音铃声跟随呼吸.

## 使用

在线使用: https://chiyo529.github.io/yangshengzhu/ . 也可下载本仓库, 双击 `index.html` 本地离线使用, 无需安装依赖.

- 吸气和呼气每阶段支持 1 至 60 秒, 以 0.5 秒为单位.
- 支持暂停、继续、重置及音量调整.
- 开始前显示 3、2、1 准备倒计时, 准备时间不计入总时长, 可取消. 暂停后继续不重复准备倒计时.
- 两枚试听按钮可分别试听吸气的单次铃声和呼气的双次铃声.
- 吸气、呼气使用 TibetBell 实录的 9.4 至 18 秒、19.4 至 30 秒片段, 结束时播放 Bell-A.
- 音频已内嵌, 无语音, 不依赖在线音频文件. 试听保留完整片段, 练习中会在阶段结束前淡出较长余韵. 来源和许可见 [AUDIO-CREDITS.md](AUDIO-CREDITS.md).
- 浏览器允许时会在本机记住最近设置, 不上传数据或保存练习历史.
- 使用时请保持设备唤醒; 锁屏、休眠或系统限制可能中断声音.

以舒适为准, 不需要吸满、呼尽或屏息. 如有头晕、手麻或憋气等不适, 停止练习并恢复自然呼吸.

## 文件

- `index.html`: 页面入口.
- `styles.css`: 样式.
- `core.js`: 参数校验和呼吸时间轴.
- `app.js`: 交互、准备倒计时、钟声和动画.
- `bell-sounds.js`: 三种录音提示音的内嵌数据, 离线使用时必须保留.
- `AUDIO-CREDITS.md`: 音频来源、裁剪和许可说明.

## GitHub Pages

这是无需构建的静态网页. 在仓库 Settings / Pages 中, 选择 Deploy from a branch, 使用 `main` 分支的 `/ (root)` 目录即可发布. 私有个人仓库需要支持私有仓库 Pages 的 GitHub 套餐.

仓库保持私有时, 发布后的网页及其 HTML、CSS、JavaScript 仍可被网页访问者获取.
